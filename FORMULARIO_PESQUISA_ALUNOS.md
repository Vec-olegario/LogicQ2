## 🧠 Seção 2: A Dor (O Desafio do Ensino Tradicional)
*Esta é a seção mais importante! É aqui que você vai extrair os gráficos de "dificuldade" para mostrar na sua apresentação.*

**3. Em uma escala de 1 a 5, quão difícil é para você visualizar na prática os conceitos teóricos ensinados nas aulas?** *(Ex: Como funciona a Curva ABC, as regras FIFO/FEFO, ou endereçamento de porta-pallets)*
- ( ) 1 - Muito fácil (consigo visualizar tudo perfeitamente).
- ( ) 2 - Fácil.
- ( ) 3 - Neutro.
- ( ) 4 - Difícil (a teoria parece muito distante da realidade do galpão).
- ( ) 5 - Muito difícil (sinto que é excesso de teoria e quase nada de prática real).

**4. Como você avalia o seu nível de engajamento e atenção durante aulas puramente teóricas (leitura de slides e apostilas)?**
- ( ) Alto, consigo manter a atenção facilmente em toda a aula.
- ( ) Médio, mas frequentemente me sinto entediado ou me disperso.
- ( ) Baixo, acho o formato cansativo e é muito difícil manter o foco.

**5. Você já sentiu dificuldade em entender o impacto financeiro ou as consequências operacionais de um erro logístico apenas lendo sobre ele?** *(Ex: O real prejuízo de errar uma contagem no recebimento ou mandar o produto errado no picking)*
- ( ) Sim, a teoria não mostra o "peso" real do erro, parece apenas um detalhe no papel.
- ( ) Às vezes, depende se o professor dá bons exemplos.
- ( ) Não, consigo entender perfeitamente todas as consequências financeiras.

**6. Durante o seu curso, com que frequência você participa de atividades que simulam o trabalho em equipe sob pressão?** *(Como gerenciar picos de pedidos, dividir tarefas na doca ou resolver gargalos)*

- ( ) Raramente, a maioria dos trabalhos são teóricos, pesquisas ou resumos.
- ( ) Nunca participei de nenhuma atividade prática simulada.

**7. Você acredita que as provas teóricas tradicionais (múltipla escolha/dissertativa) são suficientes para medir se você seria um bom profissional de logística na prática?**

- ( ) Não, eu sinto que poderia tirar nota máxima na prova teórica e ainda assim "travar" na frente de um sistema WMS real.

**8. Você sente que a falta de acesso a ferramentas práticas (como um sistema real de WMS ou laboratórios de simulação) te deixa inseguro para o mercado de trabalho?**

- ( ) Não, apenas ler a teoria já me dá total segurança.

**9. Qual é o seu maior medo ou insegurança caso fosse assumir uma vaga operacional em um grande Centro de Distribuição amanhã?**

## 💡 Seção 3: Validando a Solução (A Ponte para o LogiQ)
*Nesta seção, o próprio aluno vai validar que a sua ideia (o LogiQ) é necessária.*

- ( ) 1 - Não ajudaria em nada.

- ( ) 4 - Ajudaria muito a fixar o conteúdo que o professor passa.

**11. Como você acredita que o erro deve ser tratado durante a sua formação técnica?**

**12. De qual forma você acha mais fácil absorver lógicas de processos difíceis?**
